## `01 / IDENTITY`

**Deddy Ratnanto** — known as **`drat`**.

I work where technology, data, intelligence, and real-world operations converge. My focus is the architecture of systems: understanding the mission, connecting fragmented capabilities, engineering the platform, and making the result operationally useful.

I am interested in more than writing code. I care about the whole chain: **problem framing → system architecture → engineering → integration → operational impact**.
